允许在本机导入、试用和保存这些图片；没有把它们添加到公共示例或上传远端的授权。新增 `.fxweave-local/` 忽略目录用于实际素材工程、截图和完整记录；把源工程和依赖嵌入包、时间/参数、文件哈希、操作步骤、结果、后续继续位置保存在其中。提交的测试工具/报告只含路径、哈希、结果与合成替代图，不含原图片、带图片的 JSON 或实际素材截图。Unity 项目只读，不启动 Unity，不改其已有工作区文件。

基于三张现有源图在 UI 中派生本地工程，更换素材后至少改一处节点属性或连接，再验证生成/预览身份、关键参数、固定时间、透明边、原图对照和正式保存重开。记录实际观察，不只检查画面像素哈希改变。发现图缺陷用通用节点修复；发现工具缺陷用最小复现修复。纯数学定义下的圆形在非正方形 UV 上呈椭圆属于需记录的语义；如果本地用途中不适用，用现有通用向量/运算节点修正长宽比并记录派生图，不暗改已版本化节点语义。

### 两处交互改进

1. **预览放大**：可从工作台进入更大的预览视图并返回。沿用当前构建、素材、参数与时间状态；暂停时放大/返回画面不自行推进。提供明确关闭/返回动作和 Esc，不遮挡关键控制；保留原图/效果比较。不要为放大视图另造 Shader 或第二套生成语义。
2. **适配全部节点**：按钮与 `F` 根据节点实际边界和画布可视尺寸设置布局 viewport，让 03/05/09 全部节点和根可见，保留合理边距。长图允许缩小到能看全的尺度，再可放大继续编辑。文本输入聚焦时 `F` 不抢键盘。适配只改变布局，不能改变图语义、构建 ID 或生成 GLSL。

## 3. 本阶段不做什么

不新增效果种类、平台/管线、Unity Shader 导出、全屏 CRT、社区或账号；不全面重构工作台。不把项目图片/截图发布到 GitHub。代理试用、同日重开与未来人工跨日使用分别记录；本阶段技术 PASS 不冒充最终 V0 持续自用认证。

## 4. 每轮固定工作流

开始检查工作区及本轮范围。**Debug 自检**：最小图/最短操作路径，定位图、编译、资源导入、预览或布局层；覆盖成功/失败/空/旧画面/缺素材与保存取消相关状态。**架构自检**：源图/IR/生成器/运行适配器仍统一；放大预览不复制语义；viewport 和 UI 展开状态不参与构建；素材试用文件保持本地、Unity 文件保持只读。UI 改动有可重复 Chrome smoke，格式/状态改动覆盖导入、导出和保存重开。

每轮报告：轮次、目标、完成内容、Debug 自检、架构自检、验证命令与结果、提交哈希和 push、下一轮、是否消耗缓冲轮。验证失败不得提交；提交或推送失败不得推进。

## 5. 每轮通过后提交推送工作流

验证相应 `typecheck`、测试、构建/Chrome smoke 后执行 `git diff --check`，检查定向暂存文件，提交并推送，再核对远端。沿用 Git 单命令覆盖失效代理的既有做法。不要暂存 `.fxweave-local/`、Unity 文件或无关文件。没有功能变更的试用轮可提交文字观察记录和可重复工具；不得用空提交冒充工作。

## 7. PASS 标准

三件实际图片上的节点派生工程可生成、预览、修改、保存并重开；全部是图生成而无手写效果补丁。大预览与适配全部节点通过真实浏览器验证，布局变化不影响构建。普通测试与本地实素材路径可分别重跑。远端仅含代码、合成回归素材与文字报告，原项目未被修改。当前日期、实际操作者、操作耗时范围如实记录，人工跨日继续编辑仍标待验证。
