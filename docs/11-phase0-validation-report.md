## 实现与源图契约

- `src/graph/schema.ts` 定义版本 1 的 `GraphDocument`：`graphKind`、节点、边、暴露参数及稳定 ID；`GraphLayout` 单独保存位置、视口和选中状态。语义 JSON 对数组及对象键排序，布局变化不改变语义指纹。
- `src/graph/registry.ts` 定义图种类、唯一输出根、节点类型、端口和属性。仅注册 `foundation.test` 及 Number、Vector 2、Add、Pass、Test Output 五种测试节点。
- `src/graph/connections.ts` 与 `validation.ts` 是连接和图约束的唯一规则来源：端口方向及类型、输入唯一、唯一根、必填输入、无环、属性值、参数引用。无效连接立即拒绝并给出原因；缺线等未完成图可保存并在问题列表显示。
- `src/graph/commands.ts` 与 `history.ts` 负责不可变编辑、原子操作和撤销重做。React 组件只使用图核心返回的命令结果与诊断，不复制端口语义。
- `src/graph/project.ts` 的 `projectVersion: 1` 工程文件保存图与布局，`rendererTarget: null`。确定性序列化与导入诊断阻止不兼容版本或格式损坏覆盖当前工程。文件扩展名为 `.fxweave.json`。
- `src/storage/projectStorage.ts` 负责文件选择器、便携 JSON 下载导入和 `localStorage` 恢复草稿。草稿与正式文件状态分别显示；打开较旧文件时可选择文件或较新的本机草稿。

## 复现演示

1. 安装 Node.js 24 和桌面 Chrome；在仓库根目录运行 `npm ci`、`npm run dev`，打开输出的本地地址。
2. 点 **Create test graph**。空测试图显示 Test Output 缺少必填输入；搜索并添加 Number，从其 `float` 输出端拖到 Test Output 的 `float` 输入端，问题数变成 0。
3. 选中 Number，在 Inspector 中修改 Value、点 **Expose as parameter**，修改参数并试用 Undo/Redo。拖动节点、滚轮缩放和空白处平移。
4. 添加 Vector 2，尝试把 `vec2` 接到 Test Output 的 `float` 输入端；界面立即解释类型不兼容，原有效连线保持不变。两枚 Pass 节点可复现环被拒绝。
5. 用 **Save As** 保存工程，返回入口后 **Open project file**；核对节点、连线、参数、数值和布局。修改后重开可选择恢复较新的草稿。也可用 **Export JSON** 与 **Import JSON** 往返。

Debug 自检：最小测试图从缺少输入到合法连通、错误类型、环、撤销重做及重开均有可重复用例。输入框焦点保存、滚轮缩放、拖线和节点重叠在缓冲轮修复，新增浏览器 smoke 防止回归。损坏或不支持的工程文件不会替换正在编辑的图。

架构自检：图是唯一可编辑语义源；画布布局与语义哈希分离；节点规则留在注册表及纯图核心；文件/草稿状态与 UI 显示分层。源码没有接入正式 renderer、Shader 生成或平台适配。

## 已知缺口与下一决策

- 只提供一个用于验证基础设施的测试图种类。无法生成可运行 Shader，也不能用它完成真实效果作品或声称 V0 自用版已完成。
- 预览区仅是明确标注的占位区域。正式效果宿主、网页渲染后端，以及对应色彩、Alpha、UV 和输出语义尚未定义。
- 浏览器自动化使用桌面 Chrome；文件选择器路径通过受控测试句柄验证，JSON 下载导入走真实浏览器路径。原生操作系统文件对话框及其他浏览器尚未人工验收。
- 浏览器恢复草稿保存在当前浏览器的本地存储中；没有账号、云同步或跨设备恢复。

规划验收通过后，需由用户从近期要制作的 2–3 个真实效果出发，确认**一个首个效果宿主与网页渲染后端**，再制定生成和同源实时预览的下一阶段目标。Phase 0 执行线程不自行选择该目标。
