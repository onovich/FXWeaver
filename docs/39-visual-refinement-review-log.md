imagegen 正常晶体护符替换占位素材，三效果由原节点真实渲染；预览和卡片主体放大，运行覆盖值优先，100%节点标题与端口清晰。09入口的越界运行值导致INVALID_PROJECT，修为0.55后入口恢复。选中暴露节点仅显示关联说明，默认值编辑仍需找到全量定义列表，因此继续打回。

## 第三版：FAIL，当前值被底栏遮挡

选中暴露节点增加直接默认值控件，全量定义折叠，概览/编辑提示与类型颜色一致。1440×900截图中字段被长说明挤到约845px且底栏遮挡，要求输入框紧跟节点名称、说明后置并折叠长描述。

## 第四版：PASS，达到本轮自用视觉标准

1440×900和1024×900的当前默认值完整首屏可见。规划者独立在真实IAB（1280×720）完成：打开Radial burn、Fit all、选择Number、100%编辑、Edge width default修改为0.045、撤销恢复、返回运行调参、Radius改0.3、Split比较、放大、Escape返回且比较保留。小窗口亦能直接看到输入框。

独立最终复跑：typecheck、build PASS；72单测、44公共Chrome/WebGL2回归、14生产回归（独立4174）和5尺寸/模式截图检查全部PASS。检查测试差异保留保存重开、错误、焦点、实时参数与同画布状态验证；新增关联默认值编辑/撤销/导出及Scene覆盖分离验证。
