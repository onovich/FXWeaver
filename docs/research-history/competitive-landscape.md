# 节点式 Shader / 材质工具竞品速查

核对日期：2026-09-28。只记录官方文档、官网或项目维护者仓库可直接证实的能力；“未核实”不代表该功能不存在。

## 已核实的竞品边界

| 产品 | 节点、预览与输出 | 分发、协作与收费线索 |
| --- | --- | --- |
| **Unity Shader Graph** | Unity 编辑器内的可视化 Shader 作者工具，连接节点后即时反馈；一个 Graph 可设置 Built-in、URP、HDRP target，但官方明确警告不同管线的视觉结果可能不同。支持 URP 2D Sprite Lit Graph、子图复用、自定义 HLSL 函数、查看生成代码。[概览](https://docs.unity.cn/Packages/com.unity.shadergraph%4017.0/manual/) · [Target](https://docs.unity.cn/Packages/com.unity.shadergraph%4017.0/manual/Graph-Target.html) · [2D Sprite](https://docs.unity.cn/6000.3/Documentation/Manual/urp/ShaderGraph.html) · [子图](https://docs.unity.cn/Packages/com.unity.shadergraph%4017.0/manual/Sub-graph) · [自定义函数](https://docs.unity.cn/Packages/com.unity.shadergraph%4017.6/manual/Custom-Function-Node.html) · [生成代码](https://docs.unity.cn/Packages/com.unity.shadergraph%4017.3/manual/Upgrade-Guide-10-0-x.html) | 随 Unity 工具链提供；官网当前列 Personal 免费、Pro 订阅等方案，收费并非 Shader Graph 单独定价。[Unity 方案](https://unity.com/products) |
| **Blender Shader Editor** | Cycles / EEVEE 材质由节点树定义；面向 Blender 场景。其 glTF 导出器只能根据*识别的节点和连接*构造 glTF 材质，文档列出 Metal/Rough PBR 与 Unlit 等受支持形式，不能把任意 Blender 节点网络等价导出成目标引擎 Shader。[Shader Editor](https://docs.blender.org/manual/en/5.0/editors/shader_editor.html) · [glTF 材质导出](https://docs.blender.org/manual/en/4.2/addons/import_export/scene_gltf2.html) | Blender 免费且按 GPL 分发，创作内容归作者；本行不声称存在实时协同编辑。[许可](https://www.blender.org/about/license/) |
| **Unreal Material Editor** | 引擎内节点式 Material Expressions / Functions 生成 HLSL；有节点搜索、函数复用、材质实例参数和可查看的只读 HLSL。定位为 Unreal 原生材质工作流，而非跨引擎导出器。[节点编辑](https://dev.epicgames.com/documentation/unreal-engine/placing-material-expressions-and-functions-in-unreal-engine) · [基础与代码](https://dev.epicgames.com/documentation/unreal-engine/essential-unreal-engine-material-concepts) · [实例 / 函数](https://dev.epicgames.com/documentation/unreal-engine/unreal-engine-materials) | 属于 Unreal 授权体系；官方当前说明游戏产品收入超过门槛后适用版税，不能把此价格理解为单独的材质编辑器收费。[许可](https://www.unrealengine.com/license) |
| **Godot VisualShader** | Godot 编辑器内把节点图转换为其 Shader 脚本；提供带类型的接口、Expression 代码节点，覆盖 Godot 的材质工作流。[VisualShader](https://docs.godotengine.org/en/stable/classes/class_visualshader.html) · [编辑教程](https://docs.godotengine.org/en/stable/tutorials/shaders/visual_shaders.html) | Godot 按 MIT 许可分发，可商用；文档未将 VisualShader 作为独立订阅服务销售。[许可](https://docs.godotengine.org/en/stable/about/complying_with_licenses.html) |
| **PlayCanvas Shader Editor（独立工具）** | 网页节点编辑器，有图、材质、纹理、参数和图/材质预览；项目存浏览器 IndexedDB，可手动保存 / 加载，导出供运行时使用的 Shader Pack，其中是生成的代码与参数值，**不含节点图**。[简介](https://developer.playcanvas.com/shader-editor/introduction/) · [界面](https://developer.playcanvas.com/shader-editor/window-layout/) · [文件与导出](https://developer.playcanvas.com/shader-editor/overview/file-handling/) | 不应把 PlayCanvas **主 Editor** 的实时协作直接算到这个独立 Shader Editor 上。主 Editor 有实时协作与免费 / 付费方案（免费、公有项目；Personal 私有项目等）；独立 Shader Editor 的单独价格、多人同图协作未从文档核实。[主 Editor 协作](https://developer.playcanvas.com/user-manual/editor/realtime-collaboration/) · [方案](https://playcanvas.com/plans) |
| **Babylon.js Node Material Editor** | Babylon.js 官方提供浏览器 [Node Material Editor](https://nme.babylonjs.com/)；官方文档称 Node Material 可在不手写 Shader 代码的情况下制作自定义材质，且其 MCP 工具支持图的创建、编辑、验证、导入与导出。[材质文档](https://github.com/BabylonJS/Documentation/blob/master/content/features/featuresDeepDive/materials.md) · [编辑器工具文档](https://github.com/BabylonJS/Documentation/blob/master/content/toolsAndResources/mcpServers.md) | 已是一个网页节点材质工具；本次未核实它的独立收费、多人实时协作或向 Unity 导出的能力。[Babylon.js 官网工具入口](https://github.com/BabylonJS/Website/blob/master/src/content/site.json) |
| **Material Maker** | 桌面开源程序，200 多个节点，偏程序化 PBR 材质 / 贴图；导出随目标而异：生成 PNG；Unity 可生成 `.mat`，Godot 可生成 `.tres`，Unreal 5 使用 Python 脚本、纹理与 Shader 文件，Blender 输出贴图后需在其 Shader Editor 建材质。因此“支持多引擎”不等于任意实时 Shader 图无损移植。[官网](https://materialmaker.org/) · [导出细节](https://rodzill4.github.io/material-maker/doc/export.html) | 项目仓库默认 MIT 许可；官网有社区素材库，官方文档说明可上传 / 下载材质和节点。未核实 Steam / itch 的具体售价。[仓库许可](https://github.com/RodZill4/material-maker) · [社区库](https://www.materialmaker.org/doc) |
| **ShaderFrog 2.0** | 维护者仓库将其称为 Hybrid Graph 编辑器；核心以 GLSL 图编译出 GLSL 与元数据，再由 Three.js / Babylon.js 等引擎插件接入。公开独立编辑器仓库可本地运行，但仓库说明这个独立版本不能持久保存图，生产站点另有数据库。[编辑器仓库](https://github.com/ShaderFrog/editor) · [核心仓库](https://github.com/ShaderFrog/core) | 编辑器仓库为 MIT；维护文档说明网站有付费 / Pro 特性，但未从可访问的一手页面核实当前价格或网站导出能力。公开的 Three.js 导出提案仍是 Issue，不能据此认定已上线。[维护说明](https://github.com/ShaderFrog/editor/blob/main/CONTRIBUTING.md) · [导出提案](https://github.com/ShaderFrog/editor/issues/2) |
| **Three.js TSL 与官方示例** | TSL 是以 JavaScript 表达节点逻辑的 Three.js Shader 系统，可编译到 WebGPU/WGSL 或 WebGL/GLSL；官网另有 TSL Editor 浏览器示例。这说明“网页节点编辑 + WebGPU”本身已有人做，但官方资料未把这个示例描述成可向 Unity / Unreal 导出的完整产品。[TSL 指南](https://threejs.org/tsl/) · [官方示例](https://threejs.org/examples/webgpu_tsl_editor.html) | Three.js 技术与示例；这里未核实独立商业定价、云端图协作或跨引擎资产导出。[TSL 指南](https://threejs.org/tsl/) |

## 对产品定位的推论（待用户验证）

1. **不能只卖“拖节点、连线、实时预览”。** Unity、PlayCanvas、Babylon.js、Godot、Three.js 示例均已覆盖核心交互。[Unity 概览](https://docs.unity.cn/Packages/com.unity.shadergraph%4017.0/manual/) · [PlayCanvas 简介](https://developer.playcanvas.com/shader-editor/introduction/) · [Babylon.js 编辑器](https://nme.babylonjs.com/) · [Godot](https://docs.godotengine.org/en/stable/tutorials/shaders/visual_shaders.html) · [Three.js 示例](https://threejs.org/examples/webgpu_tsl_editor.html)
2. **最值得试的差异是“可交付的跨环境结果”。** Blender glTF 有可识别节点的边界，Unity 跨管线结果也可能变化，Material Maker 各目标导出形式不一；因此可为每个目标提供清晰的“支持 / 降级 / 不能转换”报告和目标引擎内验证项目。此项是从官方限制推导的产品假设，并未证实用户愿意付费。[Blender](https://docs.blender.org/manual/en/4.2/addons/import_export/scene_gltf2.html) · [Unity](https://docs.unity.cn/Packages/com.unity.shadergraph%4017.0/manual/Graph-Target.html) · [Material Maker](https://rodzill4.github.io/material-maker/doc/export.html)
3. **协作、版本与交接可能比节点数量更有用，但不是无人竞争。** PlayCanvas 主 Editor 已有实时协作和版本控制；独立 Shader Editor 文档却写明本地 IndexedDB 存储、运行时包不含节点图。可试“带图的可复现分享链接、版本差异、参数预设、交付源码 + 依赖清单”；须通过访谈确认是否解决真实痛点。[主 Editor 协作](https://developer.playcanvas.com/user-manual/editor/realtime-collaboration/) · [主 Editor 版本控制](https://developer.playcanvas.com/user-manual/editor/version-control/) · [独立 Shader Editor 文件](https://developer.playcanvas.com/shader-editor/overview/file-handling/)

## 尚未核实

- 各竞品的真实用户规模、留存、收入与付费转化；官方功能页不能证明市场需求。
- ShaderFrog 生产站点当前定价、免费层限制与导出按钮的实际可用性。
- PlayCanvas 独立 Shader Editor 是否支持多人实时编辑同一张图，以及独立商业价格。
- 各工具导出的 Shader 在目标引擎不同版本、渲染管线及移动设备上的兼容率；需实测样例集。
